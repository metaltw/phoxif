# phoxif — Repo 概覽

**狀態:** ✅ 現況記錄(2026-07-06)

## 這是什麼

phoxif 是一套 EXIF metadata 批次處理工具,用於相片/影片收藏的整理:
依 EXIF 拍攝時間重新命名、修正檔案時間戳、去重複、批次補寫 GPS、
依地點自動分類、HEVC 影片轉檔,並附一個網頁 UI 供人工分類無法辨識的檔案。

這是一個 **public repo**——原本是個人相片整理需求,之後泛化為公開工具。
所有個人設定(路徑、GPS 座標)一律放在 gitignored 的 `config.yaml`,
repo 只提交 `config.example.yaml` 範本。

## 功能

- **Rename by date** — 依 EXIF `DateTimeOriginal` 轉成 `YYYYMMDD_HHMMSS.ext`
- **Fix FileModifyDate** — 讓檔案系統時間對齊 EXIF 拍攝時間
- **Deduplicate** — 以 MD5 偵測並移除重複檔案
- **GPS batch write** — 從可設定的地點對照表批次補寫缺失的 GPS metadata
- **Location-based organization** — 依反查地理位置自動分類到資料夾
- **HEVC video compression** — macOS VideoToolbox 硬體加速轉檔
- **Web UI for manual sorting** — 瀏覽器介面,人工分類無法自動辨識的檔案

## Tech Stack

- Python 3.12(uv 管理)
- exiftool — EXIF 讀寫
- ffmpeg + VideoToolbox — HEVC 編碼
- Nominatim API — 反查地理位置

## 目錄結構

- `phoxif/` — 套件原始碼(convert / organize / sorter / write_gps 等模組)
- `frontend/` — Web UI(手動分類介面)原始碼
- `docs/` — 設計文件與 workflow 說明
- `assets/` — App 圖示等靜態資源
- `reports/` — 本報告所在,war_room repo-reports 規範入口
